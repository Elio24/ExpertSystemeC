# LO21 — Système expert en C

Projet réalisé en équipe dans le cadre de l’UE LO21.

Le programme part d’une liste de faits et applique des règles pour en déduire de nouveaux. Le fichier `main.c` lance deux jeux d’essai : un diagnostic automobile et une classification animale. Pour chacun, le programme affiche les faits de départ et le résultat obtenu.

## Lancer les jeux d’essai

Avec GCC et Make, depuis le dossier du projet :

```sh
make
./expert_system
```

Le [rapport du projet](Rapport%20Projet%20LO21.pdf) accompagne le code.
